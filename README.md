# digital-hero-assignment

This project is built for the Digital Heroes Training Task.

## Projects
- `frontend`: Next.js web application
- `backend`: Express API server
- `leaddesk-mini`: Prisma and database schema (if applicable)

## Running Locally
1. Start the backend: `cd backend && npm install && npm run dev`
2. Start the frontend: `cd frontend && npm install && npm run dev`
